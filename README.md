# Personal Portfolio Website

A modern, responsive personal portfolio and multi-page web application built for **Ezra Wanyama Waswa**, Computer Science undergraduate at University of the People and community technical lead based in Nakuru, Kenya. 

## Features
- **Responsive Multi-Page UI:** Client-side page navigation with a built-in interactive mobile hamburger menu controller.
- **Academic Background & Honors:** Highlights BSc. in Computer Science studies, merit-based scholarships, and certifications.
- **Production Portals:** Showcases live system links including Nakuru Tech Hub, UniRoute, and mobile developer tools.
- **Professional Tiers & Services:** Detailed web development service tiers and pricing structures.

## Built With
- HTML5, CSS3, and JavaScript (Vanilla & Mobile-first design)
- Hosted statically via GitHub Pages
